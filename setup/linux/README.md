# Linux

| Folder | What it holds | Use it for |
| --- | --- | --- |
| [`global/`](./global/) | Files for your home directory, laid out exactly where they go | Every Claude Code and Codex session on this Linux machine |
| [`project/`](./project/) | Flat set of files to copy into a repository | One repository, including cloud sessions on claude.ai/code |

Install `global/` once per machine, then copy `project/` into each repository you want covered. See each folder's README for the steps.
